# 0012: パネルの外部ブラウザー表示を既定ブラウザーへの引き渡しに限定し、capability を露出しない

- Status: Accepted
- Date: 2026-07-31
- Supersedes: なし
- Superseded by: なし

## Context

canvas パネルは狭く、長い文書を読み続ける用途では独立したブラウザーウィンドウのほうが
適する場合がある。現在この操作はシェル UI からのみ要求でき、エージェントへ依頼して
表示させる経路がない。

一方、パネル URL には ADR 0007 のインスタンス capability が含まれる。この capability は
インスタンスと同じ寿命を持ち、個別に失効させる手段を持たない。ホストの `open()` 戻り値は
canvas 契約上この URL を返す必要があるが、それ以外の経路で URL を配ると、capability が
会話ログ、要約、テレメトリ、拡張のログへ複製され、失効できない秘密が増える。

同時に、起動するブラウザーや URL を呼び出し側が指定できると、任意プロセス起動と
任意 URL の外部起動という面を新たに作ることになる。文書内リンクの外部起動は、
ユーザーが URL を確認してから承認する別経路として既に存在する。

## Decision

外部ブラウザーでの表示は、**拡張プロセスが自インスタンスのパネル URL を OS の既定
ブラウザーへ引き渡す操作**としてだけ提供する。

- 引き渡しを要求できる経路は、シェル UI と、ホスト経由の canvas アクション契約に限る。
  シェル origin の要求は ADR 0007 の認証境界を通り、アクションはホストの契約を通る。
- 引き渡す URL は当該インスタンスのパネル URL に固定し、呼び出し側から URL を受け取らない。
  文書内リンクの外部起動は、URL を提示して承認を求める別経路として維持する。
- 起動先は OS の既定ブラウザーに限る。呼び出し側はブラウザーや実行コマンドを指定できない。
- capability を含む URL 文字列を、ホストの `open()` 戻り値以外でインスタンスの外へ出さない。
  アクションの戻り値、状態問い合わせ、通知、ログ、診断のいずれにも含めない。
- 外部ブラウザーの表示は、同じインスタンスの状態とイベントを共有する追加クライアントであり、
  独立した寿命を持たない。インスタンスの close とともに失効する。
- 起動の成否は、URL を含まない結果として返す。

## Alternatives considered

- **capability 付き URL をアクションの戻り値や状態として返し、貼り付けで開かせる**:
  URL を提示できる一方、capability が会話ログや要約へ複製され、インスタンスが開いている間は
  失効させられない。ADR 0007 が前提とする「インスタンス寿命に閉じた秘密」を弱めるため採用しない。
- **呼び出し側がブラウザーや URL を指定できるようにする**: 任意プロセス起動と任意 URL の
  外部起動を canvas アクションから可能にするため採用しない。
- **短命で一回限りの引き換え URL を発行する**: URL の提示と失効を両立できるが、未認証の
  引き換え経路と失効管理を新たに抱える。既定ブラウザーへの引き渡しで要求を満たせるため、
  今回は採用しない。
- **ブラウザー専用の別 origin と別 capability を用意する**: 状態共有と権限管理が二重になり、
  同じ表示に対する認証境界が増えるため採用しない。

## Consequences

### Positive

- エージェント経由の要求も、シェル UI と同じ境界と同じ引き渡し処理を通る。
- capability を含む URL が、ホスト契約以外の経路へ複製されない。
- 外部表示の権限が「自分のパネルを既定ブラウザーで開く」だけに閉じ、任意起動へ広がらない。

### Negative

- 既定以外のブラウザーを指定できない。特定のブラウザーで開きたいユーザーは OS の既定を変える。
- 拡張プロセスからブラウザーを起動できない実行環境では外部表示を提供できず、URL を提示する
  代替手段も持たない。
- 外部ブラウザーの表示は canvas を閉じると失効するため、利用者への説明が必要になる。

### Follow-up

- `docs/architecture.md` に外部ブラウザーへの引き渡し経路と不変条件を記載する。
- エージェントから依頼できる手段を実装した時点で README の操作と canvas アクションを更新する。
- 起動処理をシェル UI とアクションで共有し、失敗結果へ URL や capability が混入しないことを
  回帰テストで確認する。
- リモート実行やブラウザー選択が要件になった場合は、引き換え URL の是非を新しい ADR で判断する。
